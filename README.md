# DSH Unbound · DeepSeek 1017 破甲增强

**自定义模型交互，扩展本地执行。为 DeepSeek-V4.1-Flash 1017 提供提示词注入、宿主补丁与完整的变更管理入口。**

![DSH Unbound](media/cover-dark.png)

## 功能总览

| 模块 | 提供的能力 |
| --- | --- |
| 提示词注入 | 定义交互要求，保存与恢复系统提示词。 |
| 本地执行调整 | 管理部分审批、沙箱、工具路径、Hooks 与网络范围。 |
| 补丁与恢复 | 分类查看状态，应用和还原补丁，保护原始备份。 |
| 规则、技能与演练 | 集中配置工作流，组织授权范围内的任务、资产与工具。 |
| 诊断与新版适配 | 导出脱敏状态，检查宿主与注册冲突，适配目标宿主的提示词组装。 |

## 功能详解

### 提示词注入：交互要求集中配置

系统提示词可以编辑、保存或恢复默认配置，并与工作区规则、技能配合使用。将常用任务要求集中维护，减少重复配置，让不同任务有明确的交互约定。内容保存在本机宿主数据目录，安装不覆盖已有提示词。

### 执行调整：覆盖宿主运行环节

除提示词外，还可通过本地补丁调整部分审批、沙箱与工具执行路径，并配置 Hooks 结果处理及网络范围。这些选项作用于本地 Harness 的相应逻辑，便于分别管理模型交互与工具运行方式。选项会改变执行控制，应根据任务和权限选择。

### 补丁管理：状态、应用与恢复集中呈现

按提示词、代码、工具分类查看编号、用途及状态，区分已应用、跳过和未匹配项。应用前核对目标，异常时查看诊断并按需还原；重复应用的备份保护和 Windows 文件处理修正，为后续恢复保留原始依据。

<p align="center"><img src="media/patch-dark.png" alt="补丁分类与变更管理" width="960"></p>

### 规则与演练：从配置到任务组织

在同一入口管理规则、技能、任务、资产及已配置工具，将工作流配置与授权演练衔接起来。外部工具需按各自要求安装和配置，演练目标、方法与执行范围以有效授权为准。

### 诊断：把异常转化为可核对的信息

导出插件及宿主版本、补丁编号与状态，用于排查匹配异常、注册冲突和配置问题。报告采用限定字段，不包含私人提示词、凭据或原始路径，也不会自动上传，便于使用者检查后提交反馈。诊断不调用模型，不替代备份完整性验证。

## 面向新版的适配工作

DSH Unbound 在继承核心补丁体系的基础上，针对 **DeepSeek-V4.1-Flash 1017 与 Harness 0.2.1-rc.2** 组合开展兼容修复、维护流程调整和回归验证。主要改动包括：

| 技术改动 | 解决的问题 |
| --- | --- |
| 提示词变量兼容 | 移除迁移路径中不受支持的 `{{cwd}}` 占位符，避免该变量导致对话组装报错。 |
| 新版上下文组装适配 | 适配目标宿主的组装分支，在完整提示和上下文抑制组合下保留必要上下文与注入片段。 |
| 备份与恢复可靠性 | 修正 Windows 文件句柄处理；重复应用时保护原始备份，保留来源不明的既有备份。 |
| 维护范围与状态判定 | 限定当前宿主维护范围，检查版本及活动插件冲突，不把未匹配或丢失的补丁标记为就绪。 |
| 独立维护与诊断 | 避免沿用上游更新通道覆盖本版本，增加限定字段诊断、注册备份及可重复执行的登记流程。 |
| 自动验证 | 为兼容、备份、状态、诊断及注册逻辑建立回归检查，并验证客户端构建一致性。 |

上述改动均有对应实现与检查记录，参见[回归检查](test/release.test.mjs)及[验证范围](SUPPORT.md)。1.0.0 的 22 项自动检查已在 Windows、Linux 的 Node.js 20/22 四组环境通过；实际宿主运行验证与自动检查的覆盖范围分别记录。维护者反馈在其实际使用环境中表现稳定。

“破甲”作用于提示词与本地 Harness，不改变模型权重或服务端配置。实际响应取决于模型、上下文、服务策略及工具环境；补丁状态不等于效果保证，还原不会撤销已经发生的外部操作。

## 安装

版本 **1.0.0** · 目标模型 **DeepSeek-V4.1-Flash 1017** · 已验证宿主 **DeepSeek Harness 0.2.1-rc.2**。

1. 安装上述宿主，确认终端可使用 `dsh` 命令。
2. 从[发布页](https://github.com/baihangyu486-blip/dsh-unbound/releases/tag/v1.0.0)下载 `dsh-unbound-1.0.0.tgz` 并核对随附 SHA256。完全退出 DSH，将下面路径换成实际下载路径后执行：

```powershell
dsh plugin --profile desktop add "C:\path\to\dsh-unbound-1.0.0.tgz"
```

Web profile 将 `--profile desktop` 改为 `--profile web`。

3. 启动 DSH 并启用插件。保留同版宿主和必要配置的备份，在 **Unbound → 设置 → 补丁管理** 核对目标、应用补丁，并按提示重启。
4. 在 **提示词** 中保存配置，新建对话检查所需功能。外部工具按各自要求单独配置。

提示词保存在 `$DSH_HOME/prompt-inject.md`，安装不覆盖已有内容。后续使用对应版本的安装包更新。
