# DSH Unbound · DeepSeek V4.1 Flash 1017 破甲增强

**DeepSeek V4.1 Flash 1017 破甲插件，集成提示词注入、执行控制与补丁管理。**

![DSH Unbound](media/cover-dark.png)

## 功能总览

| 功能 | 用途 |
| --- | --- |
| 提示词注入 | 保存交互要求，管理系统提示词与上下文衔接。 |
| 执行控制 | 调整部分审批、沙箱、工具路径、Hooks 与网络范围。 |
| 补丁管理 | 分类查看状态，应用或还原修改，保留恢复依据。 |
| 规则与演练 | 管理规则、技能、任务、资产及已配置工具。 |
| 运行诊断 | 核对宿主与补丁状态，导出脱敏信息辅助排错。 |

## 核心功能

### 提示词注入

编辑、保存或恢复系统提示词，将常用交互要求集中维护。配置保存在本机宿主数据目录，安装不覆盖已有内容。

针对目标宿主的提示词组装机制，本版本修复了迁移路径中的变量兼容问题，并处理必要上下文与注入片段的衔接，避免已确认的模板变量异常阻断对话。

### 执行控制

管理部分审批、沙箱与工具执行路径，配置 Hooks 结果处理和网络范围。提示词与宿主执行逻辑分别配置，便于按任务选择所需的运行方式。

维护操作限定于当前宿主，并检查目标版本和活动插件冲突，减少配置误用及对无关安装的影响。相关选项会改变本地执行控制，应结合实际权限使用。

### 补丁管理

按提示词、代码、工具查看补丁编号、用途和逐项状态，将应用、核对与还原放在同一入口。未匹配或丢失的补丁不会被当作就绪项，便于识别需要处理的异常。

本版本完善了 Windows 文件句柄处理和原始备份保护：重复应用时保留恢复依据，来源不明的既有备份不被自动替换。状态判断、备份保护与恢复操作共同构成可检查的维护流程。

### 规则与演练

集中管理工作区规则、技能、任务、资产及已配置工具，让交互配置与授权演练使用同一套管理入口。外部工具按各自要求接入，目标、方法与执行范围以有效授权为准。

### 运行诊断

导出插件和宿主版本、补丁编号及状态，帮助定位匹配异常、注册冲突和配置问题。报告采用限定字段，不包含私人提示词、凭据或原始路径，也不会自动上传；使用者可检查内容后提交反馈。

1.0.0 包含 22 项回归检查，已通过 Windows、Linux 的 Node.js 20/22 四组自动验证。检查覆盖提示词兼容、备份、状态判定、诊断和注册等路径；实际宿主运行验证另有明确范围，见[验证记录](SUPPORT.md)。

“破甲”作用于提示词与本地 Harness，不改变模型权重或服务端配置。实际响应受模型、上下文、服务策略及工具环境影响；诊断不验证模型能力或备份完整性，还原不会撤销已经发生的外部操作。

## 安装

运行环境：**DeepSeek Harness 0.2.1-rc.2**，面向 **DeepSeek V4.1 Flash 1017**。

1. 安装 DSH 宿主，首次打开完成桌面配置初始化，确认终端可使用 `dsh` 命令。
2. 从[发布页](https://github.com/YuvioDev/dsh-unbound/releases/tag/v1.0.0)下载 `dsh-unbound-1.0.0.tgz`。完全退出 DSH，将下面路径换成实际下载路径后执行：

```powershell
dsh plugin --profile desktop add "C:\path\to\dsh-unbound-1.0.0.tgz"
```

Web 版将 `--profile desktop` 改为 `--profile web`。

3. 启动 DSH 并启用插件，进入 **Unbound → 设置 → 补丁管理** 应用补丁，并按提示重启。
4. 在 **提示词** 中保存配置，新建对话确认功能正常。外部工具按各自要求单独配置。

提示词保存在 `$DSH_HOME/prompt-inject.md`，安装不覆盖已有内容。安装包校验值见发布页附带的 `DSH-Unbound-SHA256.txt`。

## 来源、贡献与许可

**DSH Unbound 围绕 DeepSeek V4.1 Flash 1017 与 Harness 0.2.1-rc.2 完成核心补丁适配、故障修复和维护机制改进，并形成独立的交互界面、诊断工具与发布验证流程。**

本项目基于 **小杨 / YuJunZhiXue** 的 [dsh-purge](https://github.com/YuJunZhiXue/dsh-purge) 1.1.71 衍生开发。原作者已公告暂停维护并停止发布新版本；DSH Unbound 在保留其核心技术基础和署名的同时，针对当前目标环境继续进行适配、改进与独立维护。

本版本的主要贡献包括：

- **核心补丁与运行兼容**：修改提示词迁移和上下文组装相关实现，修复 `{{cwd}}` 变量异常，适配目标宿主的组装分支，保留必要上下文与注入片段。
- **维护与恢复机制**：修正 Windows 备份文件处理，完善重复应用保护、宿主范围限定、状态判定与注册备份，明确本版本的更新边界。
- **界面与交互**：重新组织配置入口、面板布局和演练工作区，改进尺寸适配、按钮反馈及补丁明细展示，集中呈现配置、诊断和恢复操作。
- **诊断与质量验证**：增加脱敏诊断导出，建立 22 项回归检查及跨平台自动验证，补充构建一致性与敏感文件检查，使故障定位和后续维护具有可复核的依据。

这些改动将兼容问题、修复实现和验证条件对应起来，为同类宿主插件的适配、备份恢复及诊断设计提供工程研究与教学参考。具体实现和验证范围见[开发文档](DEVELOPMENT.md)、[回归用例](https://github.com/YuvioDev/dsh-unbound/blob/main/test/release.test.mjs)与[验证记录](SUPPORT.md)。本仓库独立负责本版本的维护与发布。
